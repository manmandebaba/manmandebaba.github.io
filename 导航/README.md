# 个人导航页（NavPage）

一个纯前端、免部署、零依赖的个人浏览器起始页 / 导航页。双击 `index.html` 即可使用，所有数据都在本地，无需任何服务器。

## ✨ 功能特性

### 搜索与 AI
- **多引擎搜索**：百度 / Google / Bing / DuckDuckGo / 搜狗，一键切换
- **智能输入识别**：输入网址或域名直接打开；输入已保存的站点名称可精确直达；其余内容自动走搜索引擎
- **AI 助手直达**：DeepSeek / 豆包 / Kimi / ChatGPT / 元宝 / 通义千问，可设置默认助手，一键唤起

### 导航与管理
- **分类卡片导航**：按分类组织常用网站（AI 工具、开发、社交、购物、效率、影音、学习等）
- **搜索框下方收藏夹**：常用站点快捷入口
- **完整增删改查**：支持新增 / 编辑 / 删除导航项与分类，分类可拖动排序
- **图标自动抓取**：自动获取网站 favicon，内置多级兜底（站点图标 → 占位服务 → CORS base64），也可手动抓取或使用 Emoji

### 桌面小组件
- ⏰ 时钟与日期、问候语
- 🌤️ 天气组件（open-meteo 数据源，支持城市名或按 IP 自动定位，点击城市名可切换）
- ⏱️ 下班倒计时（可设置下班时间）
- 💰 发薪倒计时（每月几号发薪）
- 📅 事件组件

### 外观定制
- **主题**：跟随系统 / 日出日落自动 / 深色 / 浅色
- **背景**：极光紫、落日橙、深海蓝、森林绿、午夜黑、粉樱等预设，也可粘贴任意网页图片 URL（在线图片地址）作为自定义背景
- **细节调节**：字体、字号、字重、卡片大小、卡片透明度、页面宽度、卡片图标模式（favicon / emoji）、页脚署名

### 数据与同步
- **本地存储**：所有修改自动保存到浏览器 localStorage
- **绑定配置文件**（Chrome / Edge）：通过 File System Access API 绑定磁盘上的 `config.json`，配置实时写入磁盘，多个浏览器绑定同一文件即可多端共享、实时同步
- **导出 / 导入**：配置一键导出为 JSON 或导入恢复
- **重置**：一键恢复默认配置

## 📁 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 应用主体（结构与全部逻辑，单文件） |
| `style.css` | 样式表 |
| `config.js` | 默认配置（未绑定 / 重置时使用） |
| `config.json` | 已绑定的磁盘配置文件（可跨浏览器同步） |
| `README.md` | 本说明文件 |

## 🚀 快速开始

1. 直接用 Chrome / Edge 打开 `index.html`
2. 顶部提示条点击「绑定配置文件」可创建磁盘配置文件（可选，推荐）
3. 右上角 ⚙️ 打开设置，按需调整主题、搜索、小组件、分类等
4. 完成，开始使用

> 提示：使用 Chrome / Edge 可完整体验绑定配置文件、多浏览器同步等功能。

## ⚙️ 配置说明

核心配置保存在 `config.json`（或浏览器本地存储）中：

- `title`：页面标题
- `settings`：主题、搜索引擎、AI 助手、背景、天气城市、下班时间、发薪日、各组件开关及样式参数
- `favorites`：搜索框下方的收藏夹数组
- `categories`：分类数组，每项含 id / 名称 / 图标 / 排序与导航项列表

> 提示：`config - 副本.json` 为配置文件备份，可直接删除。

## 🔧 技术要点

- 纯原生 HTML / CSS / JavaScript，无任何第三方依赖
- 天气数据来自 open-meteo（免费、无需 Key）
- 多浏览器同步依赖 File System Access API（需 Chrome / Edge），其他浏览器自动降级为本地存储
