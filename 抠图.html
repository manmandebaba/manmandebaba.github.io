    使用说明

    快速上手（推荐流程）

    • ① 拖入图片（默认自动开抠，无需点任何按钮）
    • ② 看右栏结果，满意直接点"下载当前"
    • ③ 不完美？先拖"残留清理 / 主体补全"滑块快速修正（10 秒搞定）
    • ④ 还不行？切"点选 / 修补"模式：点"排除"去掉残留，点"保留"补回缺失
    • ⑤ 复杂图（坐姿、杂乱背景、多人物）：左栏模型选"高清版 RMBG"，主体完整度最好

    两种抠图模式

    • 自动抠图：一键完成。三个模型档位：快速版（40MB，日常够用）、精细版（80MB，发丝细节）、高清版 RMBG（44MB，复杂场景/坐姿人像更准，主体完整度最好，推荐）。
    • 点选抠图：手动指定主体，适合复杂背景、多物体场景。

    点选抠图操作

    • 框选（推荐）：默认模式，按住鼠标左键拖框包住要保留的主体，一次搞定。选完后留下紫色矩形标记（单击可删除），和保留/排除点一样可见
    • 添加保留点：点"保留"按钮切换模式，左键点击要保留的区域
    • 添加排除点：点"排除"按钮切换模式，左键点击误选的区域（如头发间隙的背景）
    • 删除点：单击已存在的点（绿色/红色圆点）即可删除
    • 切换点类型：双击已存在的点，保留 ↔ 排除 互切
    • 撤销/清空：底部按钮可撤销最后一个标记（优先撤销框选）或清空所有
    深紫色区域 = 当前选中效果，亮紫色描边 = 选中边界，实时可见
    处理时画面底部会显示浮动进度条（模型下载百分比 / 编码中 / 解码中），光标变等待样式；首次使用点选需下载约 40MB 模型，请耐心等待
    推荐流程：先框选整个人体 → 再用"排除"模式点掉误选的背景（头发间隙、手臂旁边）
    点选模式是从头开始抠，不是在自动抠图结果上修补。框选可以快速选中完整主体，比点很多点方便得多。

    修补模式（默认开启，推荐）

    • 流程：先用"自动抠图"得到结果 → 切到"点选 / 修补"（修补模式默认已勾选）
    • 排除：点残留的 background 区域（如腰带、下摆处没抠干净的色块），SAM 会识别该处物体并从结果中减去
    • 保留：点被误删的区域（如镂空处、半透明处），SAM 识别后加回结果
    • 撤销：每次修补都可逐步撤销（保留最近 8 步）；"清空"恢复到修补前的结果
    • 框选修补后留下绿色矩形标记，和点标记一样可见，撤销时同步回退
    • 深紫色叠加层始终显示当前保留的部分，所见即所得
    修补模式 = 自动抠图打底 + SAM 局部增删，比纯点选从零开始省力得多，效果也更好。

    批量处理

    • 拖拽多张图片到页面，或 Ctrl+V 粘贴截图
    • 添加后自动抠图（默认开启）：图片一拖入/粘贴就自动开始抠，无需再点按钮；想先调设置再抠，可在左栏关掉该开关
    • 也可点"全部自动抠图"批量处理队列中所有待处理的图片
    • 完成后点"打包下载 ZIP"一次下载所有结果

    换背景与导出

    • 抠图完成后，背景可选：透明 / 白底 / 红底 / 蓝底 / 自定义颜色
    • 渐变背景：内置暮紫 / 暖杏 / 薄荷三组渐变，适合做海报底图
    • 图片背景：选"图片背景（上传）…"，上传任意风景图/场景图作为背景，自动铺满
    • 原图背景特效：选"原图背景 · 模糊/灰度/深褐"，主体保持清晰，背景一键虚化或做旧（朋友圈氛围图神器）
    • 去白边 / 灰边：勾选后自动把前景颜色渗透到半透明边缘，消除发丝白边/灰边。换深色背景时建议开启
    • 残留清理 / 主体补全：抠完后如果边缘有半透明"鬼影"（如沙发、桌面残留），右拉滑块清除；如果主体没抠全呈半透明（如裤子、裙摆），左拉滑块补全为实心。即时生效，无需重新抠图
    • 半透明智能提示：自动抠完后若状态栏提示"约 N% 区域呈半透明"，说明可能有残留或没抠全，按提示用滑块或修补模式修正即可
    • 支持 PNG（透明）、WebP（更小）、JPEG（已换底色）三种格式
    • 边缘羽化：调整滑块（0-10px）让抠图边缘平滑过渡，减少锯齿。默认 2px，发丝细节可调到 3-4px

    布局调整

    • 栏与栏之间有紫色分隔线，鼠标悬停会高亮
    • 按住分隔线左右拖动，可以调整三栏的宽度
    • 布局会自动保存，下次打开时恢复

    抠图效果说明

    • 自动模式（ISNet / RMBG）：适合主体明确的照片，推荐优先使用。ISNet 快速但复杂场景容易丢主体细节（如坐姿的腿部）；RMBG 高清版主体完整度明显更好，复杂图建议直接选它
    • 点选模式（SlimSAM）：适合指定抠哪个物体，但轻量版模型对发丝、复杂边缘效果有限
    • 细小的附属物（飘带末端、挂饰等）任何自动模型都可能漏掉，用"点选 / 修补"模式点"保留"补回
    • 如果点选模式效果不好，建议换自动模式，或换更精细的图片
    首次使用需联网下载模型（约 40-80MB），之后走浏览器缓存，离线可用。
    如果遇到 "Failed to fetch" 错误，说明模型下载失败。请检查网络连接，或刷新页面重试。模型走国内镜像 hf-mirror.com，一般都能正常下载。

    故障排除

    • 自动抠图失败：状态栏会显示具体失败原因（网络问题/图片格式/内存不足等）
    • 网络问题：模型托管在 cdn.jsdelivr.net 和 hf-mirror.com，确保能访问这两个域名
    • 图片格式：支持 JPG/PNG/WebP 等常见格式，不支持 GIF 动图
    • 内存不足：图片太大（>4000px）可能导致内存不足，建议压缩后重试
    • 批量失败：批量处理时会显示每张图的失败原因，方便定位问题
    • 高清版 RMBG 较慢：首次需下载 44MB 模型（走 hf-mirror 国内镜像）；有独立显卡时走 GPU 约 10 秒出结果，纯 CPU 推理需要 1-2 分钟，属正常现象，请耐心等待
